# API Reference

Base URL (local default): `http://localhost:8000`

Interactive docs are auto-generated by FastAPI and always reflect the
live schema:
- Swagger UI: `/docs`
- ReDoc: `/redoc`
- Raw OpenAPI JSON: `/openapi.json`

All endpoints are prefixed with `/api/v1` except the root health-check
landing page (`/`).

---

## Authentication

None by default — this is designed for local/private deployment behind
your own network boundary or reverse proxy. Add an auth layer (API key
header check via FastAPI dependency, or a reverse-proxy auth gateway)
before exposing this publicly.

---

## Error format

All errors return a consistent JSON body:

```json
{
  "error_code": "voice_not_found",
  "message": "Voice 'xyz' was not found.",
  "details": {}
}
```

| HTTP status | Meaning |
|---|---|
| 422 | Validation error (bad input — empty text, out-of-range speed, unsupported file type, etc.) |
| 404 | Resource not found (voice id, generated file) |
| 413 | Uploaded file too large |
| 429 | Server busy (concurrency limit reached and timed out waiting) |
| 500 | Internal error (synthesis or audio-processing failure) |
| 503 | Model failed to load, or ffmpeg missing |
| 504 | Generation timed out |

    "is_custom": false,

## `GET /api/v1/voices/{voice_id}`

Returns a single voice's details. 404 if not found.

## `POST /api/v1/voices/clone`

Clone a new voice from an uploaded audio sample.
**Content-Type:** `multipart/form-data`

| Field | Type | Required | Notes |
|---|---|---|---|
| `file` | file | yes | wav/mp3/flac/ogg/m4a, ≤ `MAX_UPLOAD_MB` (default 20MB), 3-60s of clean single-speaker speech |
| `name` | string | no | Display name for the new voice |

**Response 200**
```json
{
  "voice_id": "custom_a1b2c3d4e5f6",
  "name": "Narrator Voice",
  "message": "Voice cloned successfully from a 12.4s reference sample. Select voice_id='custom_a1b2c3d4e5f6' when generating speech."
}
```

**Errors:** `422 unsupported_audio_format`, `413 file_too_large`,
`500 audio_processing_error` (e.g. clip too short).

## `DELETE /api/v1/voices/{voice_id}`

Deletes a cloned voice. Built-in `male`/`female` presets cannot be
deleted (`400`).

## `POST /api/v1/generate`

Synthesizes speech for a single text input.

**Request body**

| Field | Type | Default | Range / Notes |
|---|---|---|---|
| `text` | string | — | Required, 1–`MAX_TEXT_LENGTH` chars (default 5000) |
| `voice_id` | string | `"male"` | `"male"`, `"female"`, or a `custom_*` id from cloning |
| `language` | string | `"en"` | ISO code: en, es, fr, de, it, pt, pl, hi, ja, ko, zh-cn, etc. (XTTS-v2 supports 17 languages) |
| `speed` | float | `1.0` | `0.5`–`2.0` (playback tempo multiplier) |
| `pitch_semitones` | float | `0.0` | `-12.0`–`12.0` |
| `output_format` | string | `"wav"` | `"wav"` or `"mp3"` |
| `generate_subtitles` | bool | `true` | Emit a `.srt` alongside the audio |
| `emotion_exaggeration` | float | `1.0` | `0.0`–`2.0`; scales delivery expressiveness/temperature |

**Example request**
```bash
curl -X POST http://localhost:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{
        "text": "Good morning! Today'\''s forecast calls for clear skies, with a high near seventy-two degrees.",
        "voice_id": "female",
        "language": "en",
        "speed": 1.05,
        "pitch_semitones": 0,
        "output_format": "mp3",
        "generate_subtitles": true
      }'
```

**Response 200**
```json
{
  "job_id": "f3a9c1e7b2d4",
  "voice_id": "female",
  "language": "en",
  "duration_seconds": 5.42,
  "audio_url": "/api/v1/audio/f3a9c1e7b2d4.mp3",
  "srt_url": "/api/v1/audio/f3a9c1e7b2d4.srt",
  "format": "mp3",
  "sample_rate": 24000,
  "sentences": [
    {
      "index": 0,
      "text": "Good morning!",
      "start": 0.0,
      "end": 0.98
    },
    {
      "index": 1,
      "text": "Today's forecast calls for clear skies, with a high near seventy-two degrees.",
      "start": 1.43,
      "end": 5.42
    }
  ],
  "processing_time_seconds": 1.87
}
```

Fetch the resulting files with the returned URLs (relative to the API
base):

```bash
curl -o speech.mp3 http://localhost:8000/api/v1/audio/f3a9c1e7b2d4.mp3
curl -o speech.srt http://localhost:8000/api/v1/audio/f3a9c1e7b2d4.srt
```

## `POST /api/v1/generate/batch`

Synthesizes multiple text items in one call. Each item is processed
independently — one item failing does not abort the batch.

**Request body**

| Field | Type | Notes |
|---|---|---|
| `items` | array | 1–`MAX_BATCH_ITEMS` (default 50) `BatchGenerateItem` objects |
| `generate_subtitles` | bool | Applied to all items (default `true`) |

`BatchGenerateItem` fields: `id` (caller-supplied string to correlate
results), `text`, `voice_id`, `language`, `speed`, `pitch_semitones`,
`output_format` — same semantics as the single `/generate` request.

**Example**
```json
{
  "items": [
    { "id": "intro", "text": "Welcome to the show.", "voice_id": "male" },
    { "id": "outro", "text": "Thanks for listening!", "voice_id": "female" }
  ],
  "generate_subtitles": false
}
```

**Response 200**
```json
{
  "batch_id": "9e1d2c3b4a5f",
  "total": 2,
  "succeeded": 2,
  "failed": 0,
  "results": [
    {
      "id": "intro",
      "success": true,
      "result": { "job_id": "...", "audio_url": "/api/v1/audio/....wav", "...": "..." },
      "error": null
    },
    {
      "id": "outro",
      "success": true,
      "result": { "...": "..." },
      "error": null
    }
  ],
  "processing_time_seconds": 3.21
}
```

## `GET /api/v1/audio/{filename}`

Serves a previously generated `.wav`, `.mp3`, or `.srt` file by the
filename returned from `/generate` or `/generate/batch`. Files are
retained for `AUDIO_RETENTION_HOURS` (default 24h) before automatic
cleanup.

Returns `404` if the file doesn't exist or has been cleaned up.

---

## Rate limiting / concurrency

There is no per-client rate limiter built in. Generation concurrency is
controlled server-side via `MAX_CONCURRENT_GENERATIONS` (default `1`,
appropriate for a single consumer GPU); requests beyond that queue on an
internal semaphore and return `429 too_many_requests` if they exceed
`GENERATION_TIMEOUT_SECONDS` waiting for a free slot. For public-facing
deployments, add a rate limiter (e.g. `slowapi`) or an API gateway in
front.
